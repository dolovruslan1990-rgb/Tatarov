Book Tracker
Автор: [Ваше Имя Фамилия]

Простой трекер для учёта прочитанных книг с GUI на Python.

Описание
Приложение позволяет:

добавлять книги (название, автор, жанр, количество страниц);

просматривать список в таблице;

фильтровать по жанру и минимальному количеству страниц;

сохранять/загружать данные в формате JSON.
